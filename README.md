# OpsRAG

**AI-assisted incident investigation grounded in operational knowledge.**

OpsRAG is a Retrieval-Augmented Generation system designed to help DevOps, SRE, Cloud, and Platform Engineering teams investigate infrastructure and application incidents.

Instead of answering only from a language model’s general knowledge, OpsRAG retrieves evidence from operational documentation such as runbooks, postmortems, infrastructure code, Kubernetes manifests, logs, and architecture documents.

The system produces structured diagnoses containing hypotheses, supporting evidence, recommended checks, source citations, and explicit limitations.

> OpsRAG is not intended to resolve incidents autonomously. It is designed to help engineers investigate incidents faster and make evidence-based decisions.
